# Keys UI kit

Дизайн-система приложения «Ключи», версия 1.0.0. Снимок утверждённого прототипа от 2 октября 2026 года.

- [Открыть дизайн-систему](https://glazest-t.github.io/keys-uikit/)
- [Руководство для разработчика и AI-агента](https://glazest-t.github.io/keys-uikit/handoff.html)
- [Логотип и фавикон](https://glazest-t.github.io/keys-uikit/#brand)
- [Компоненты](https://glazest-t.github.io/keys-uikit/#components)

## Состав

60 семейств компонентов, 85 SVG-иконок, 8 сценариев, светлая тема, Golos Text, токены типографики, цветов, размеров и движения. Каталог содержит интерактивные состояния, примеры HTML, контракты и правила поведения.

| Файлы | Назначение |
| --- | --- |
| `tokens.json`, `tokens.css`, `foundations.json` | Токены и основы |
| `key.css`, `key.js`, `templates.js` | Стили, поведение и HTML-композиции компонентов |
| `components.json`, `contracts.d.ts` | Состояния, свойства и события |
| `examples/`, `examples.json` | Отдельные примеры компонентов |
| `brand/` | Логотипы в SVG, знак ключа, фавиконы SVG / PNG / ICO и правила использования |
| `icons/`, `icons.svg`, `icons.json` | Иконки |
| `motion.json`, `motion.inventory.json`, `keyframes.json` | Анимации и переходы |
| `rendered-reference/` | Скриншоты и точные визуальные образцы |
| `reference-app/`, `reference-source/` | Снимок прототипа и исходная реализация для сверки |
| `handoff.html`, `manifest.json`, `coverage.json` | Документация, состав и границы покрытия |
| `verification.json`, `select-verification.json` | Отчёты проверок |

## Локальный запуск

```sh
python3 -m http.server 8780
```

Откройте http://localhost:8780/. Пакет автономный: сборка и установка npm-зависимостей не требуются. HTML, CSS, JavaScript, SVG и JSON находятся в редактируемом виде.

Порядок подключения компонентов: `tokens.css` → `key.css` → `data.js` → `templates.js` → `key.js`. Начните с `handoff.html`: он объясняет приоритеты токенов, контракты и границу между переносимыми примерами и полной логикой прототипа.

## Публикация

GitHub Actions публикует каталог в GitHub Pages после обновления ветки `main`. Репозиторий самостоятельный и не изменяет опубликованное приложение `keys-mobile-new`.

Данные, цены и начисления в примерах относятся к прототипу. Ключи внешних интеграций не включены: для работы интерактивных карт в снимке приложения требуется собственная конфигурация 2ГИС. Проверки не являются полной сертификацией доступности или проверкой серверных интеграций.
